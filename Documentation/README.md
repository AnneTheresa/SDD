# Voltio Documentation

Start with the [project architecture overview](onboarding/project-overview/architecture-overview.md) for a map of the application, its main request flows, and pointers for contributors.

For local installation and test commands, use the repository's [developer setup guide](../SETUP.md).
The developer assistant searches Markdown files recursively in this `Documentation/`
directory and reports paths relative to it. Feature specifications remain in `specs/`
and are not substituted for contributor documentation.

## Documentation layout

```text
Documentation/
├── README.md
└── onboarding/
    └── project-overview/
        └── architecture-overview.md
```

The onboarding overview is intended as a starting point, not a replacement for the detailed setup instructions, source code, or feature specifications.
